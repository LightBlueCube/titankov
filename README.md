关于拟真TTDM：

模块血量与受击计算：
原版的血量机制被移除，取而代之的是分6部位的局部受击机制。
6个部位分别为：反应堆，驾驶舱与四肢。
反应堆无法直接被攻击。


反应堆的血量机制：

反应堆拥有一定血量，若反应堆血量为0，则进入黄血状态，启动反应堆损坏计时器，若在计时器归零前未能修复反应堆则引发一次没有弹射的核爆。若在黄血时反应堆受到了超过250点伤害则玩家立即死亡。在其他部位受击时会扣除该次伤害10%的反应堆血量。若对驾驶舱造成的单次伤害足够，则有可能直接使反应堆受击。


部位离线：
除反应堆外的部位在受到的伤害总量超过该部位的血量后，部位将会离线。

驾驶舱：离线后无法使用除防御技能以外的技能，驾驶舱再次受击时将会导致屏幕闪烁，HUD只能显示“HUD已离线”错误，有50%概率无法弹射。

上肢：一条上肢离线时近战伤害为原来的50%，武器散布为原来的150%，换弹速度为原来的125%；两条上肢都离线则将上述参数分别调整为30%，300%，175%。

下肢：一条下肢离线时降低移动速度为原来的75%，两条均离线时只能蹲下，无法冲刺，并且移动会使驾驶舱受伤。


debuff机制：
四肢剩余血量不到50%时再次受伤可能会获得下列debuff中的任何一个：

液压故障：持续缓慢扣除该部位生命值并且降低操控性。可通过使用维护包消除。

电路故障：HUD上将标记该部位“已离线”，不显示该部位的任何参数。可通过“重启主系统”选项消除。

机械故障：作动器卡滞。上肢降低转向速度，下肢降低移动速度。只能通过备件包消除。


维修机制：
有三种维修选项。


重启主系统：用于修复电路故障。

维护包：消耗性维修品，可以恢复某个部位的血量。

备件包：消耗性维修品，可以维修离线的部位。


实现说明（仅 ttdm 模式生效）：

- 脚本：titankov/tk_parts（损伤模型真值）→ tk_fws（告警，驱动 ECAM / Logger）→ tk_maint（ECAM 交互与维修流程）；tk_eject（弹射规则）。
- 反应堆血量即原生血量，因此原版黄血、血条照常工作；但原生血量被钳制在 1 点以上，玩家不会因原生血量归零而死亡——打空反应堆时由脚本显式进入黄血，死亡只来自「黄血超 250 点」或「20 秒熔毁」。各部位血量按底盘原生最大血量的比例分配，数值常量集中在 tk_parts.gnut 顶部。
- 躯干/溅射/近战伤害由机体结构分摊到五个外部部位；暴击点命中视为驾驶舱。已离线部位再受击时 50% 进入反应堆。
- 黄血后反应堆最多再承受 250 点，20 秒内未用备件包修复则无弹射核爆。仅黄血时允许弹射，弹射后飞行员落地即死，击杀归最后攻击者。
- 电路故障的部位显示 XX 与 DATA INVALID，真实损伤被隐藏，直到重启主系统。
- 每条命：维护包 x2，备件包 x1。重启 1.5 秒（不因受击中断），维护包 1 秒 / 备件包 2 秒（受击中断，完成时才消耗）；均为设计值（6/4/8 秒）的 25%。
- 玩家无法下机：服务端每帧撤销「下机许可」并硬拦 TitanDisembark 客户端指令；唯一的离机方式是黄血弹射（下机与弹射是两条独立路径，封锁下机不影响弹射）。
- 技能冷却完成时向日志输出 `[SYS] <技能名> 就绪 READY`（战术 / 防御、火力、反骑乘，以及泰坦核心），因为原版 HUD 已被隐藏。就绪判定照抄原版冷却模型 `FwsOffhandReady`（`cooldown_type` 为 `chargeFrac` 时看 `GetWeaponChargeFraction()` 是否满 1.0，`ammo*` 类看 `IsWeaponRegenDraining()` 与弹夹是否满），只在「不可用 → 可用」的边沿报一条，每条命首次采样不报。技能名的简体中文取自 tk_fws.gnut 里按武器类名维护的 `FWS_ABILITY_NAMES` 表（服务端无法 Localize），未收录的类名回退为英文 token。追踪火箭、剑刃格挡、弹药切换不提醒（冷却极短 / 反复切换，只会刷屏）；泰坦核心武器位于 `OFFHAND_EQUIPMENT`，已从轮询里排除，避免与核心提示重复。

ECAM 交互：长按 E 进入/退出，W/S 移动光标，D 执行或展开，A 折叠，开火键中止维修。交互期间机体冻结、无法冲刺、武器收起，退出交互会中止进行中的维修。常驻的 MAINT 文件夹里有主系统重启，以及维护包 / 备件包两个子文件夹，每个部位一行（部位 读数 …… 使用）；告警里的维修步骤也可以直接执行。准心下方显示熔毁倒计时与维修进度。

原版主 HUD 与泰坦血条在泰坦存活期间一律隐藏：主 HUD 用 CE_FLAG_HIDE_MAIN_HUD，泰坦血条是客户端驾驶舱 RUI，靠 CE_FLAG_TITAN_3P_CAM 让客户端自己收起。ConVar tk_hud_hidevanilla（默认 1）控制，tk_vanillahud [0|1]（需 sv_cheats 1）可临时恢复；驾驶舱离线时同样隐藏，且右下角部位 HUD 一并隐藏、日志转为闪烁显示，作为最后手段。

界面与提示（本次更新摘要）：

- 右下角部位状态 HUD：原本是独立的 statushud mod，现已合并进 titankov（mods/statushud 已删除，ConVar 前缀由 `statushud_` 改为 `tk_hud_`）。脚本为 `tui/tui_titanhud.gnut`，在 mod.json 里以 `ServerCallback.After = TkHud_Init` 注册；纯显示层，所有数值都读 titankov 的真值。
- 27 行字符画：驾驶舱对应头部＋躯干，裆部小框对应反应堆，其余为四肢。驾驶舱一行显示「驾驶舱 COCKPIT」，裆部一行显示「反应堆 REACTOR」。
- 读数：剩余百分比；电路故障显示 XX；离线显示「离线」；机械 / 液压故障分别在读数后追加 JAM / HYD。
- 反应堆危急：裆部小框变红闪烁，并在框内显示小数点后两位的倒计时；胸口那一排横向显示「反应核心不稳定」。
- 显示时机：未重生（无存活泰坦）时不显示，重生瞬间先播一段「连接中」动画再显示；驾驶舱离线时整个 HUD 隐藏，此时界面只剩 ECAM 与日志。
- ConVar：`tk_hud_size`（默认 9）、`tk_hud_x`（0.88）、`tk_hud_y`（0.77）、`tk_hud_blink`、`tk_hud_style`、`tk_hud_lang`。
- ECAM 与日志左右拉开：ECAM x = 0.28，日志 x = 0.70；退出 ECAM 交互时会自动折叠所有已展开的子菜单。
- 日志在驾驶舱离线时随机闪烁：亮 0.08~0.55 秒、灭 0.04~0.22 秒，另有 20% 概率出现 0.30~0.90 秒的长断线，读起来像不稳定的显示而不是节拍器。
- 日志配色：泰坦核心就绪为黑底加粗黄字，技能就绪为蓝字（颜色由渲染层施加，不写进文本，避免影响折行宽度）。

上肢武器惩罚：keyvalues/ 为 7 把泰坦主武器追加了 tk_arm_fault / tk_arm_1 / tk_arm_2 配件（排在全部原版配件之后，保持网络传输的配件索引一致），分别对应上肢液压或机械故障、一条上肢离线、两条上肢离线。上肢液压 / 机械故障除武器惩罚外还会降低转向速度（液压 +0.15，机械 +0.25）；下肢液压 / 机械故障同时降低移速与转向。客户端没装本 mod 时散布与换弹按原版预测，以服务端为准。

测试命令（需 sv_cheats 1）：ecam hit <部位0-5> <伤害>，ecam fault <部位1-5> <0液压|1电路|2机械>，tk_vanillahud [0|1]（切换泰坦存活期间隐藏原版 HUD）。
